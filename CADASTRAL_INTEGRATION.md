# Кадастровая и GEO-интеграция BankrotAI

Дата актуализации: 2026-07-31.

## Источники и порядок

1. По кадастровому номеру приложение пробует публичный PKK endpoint.
2. При отсутствии результата используется НСПД.
3. Если кадастровые источники не дали координаты, адрес геокодируется через
   Nominatim/OpenStreetMap.
4. Синтетические координаты не создаются: объект получает `needs_geo_check`.

Результат сохраняется в `LotGeoSnapshot` с источником, методом, confidence,
GeoJSON, metadata и trace reason. Повторная обработка не уничтожает историю.

## TLS

`verify=False` не используется. Windows EXE подключает системное хранилище
корневых сертификатов через `truststore`; custom CA можно указать переменной
`NSPD_CA_BUNDLE`. Отключение проверки допускается только явным
`NSPD_ALLOW_INSECURE_DEBUG=true` вне production.

Ошибка сертификата НСПД не обрывает пакетный GEO worker: конкретный объект
остаётся для ручной проверки. Недоступность внешнего сервиса не считается
успешным геокодированием.

## Desktop

Вкладки карты поддерживают кадастровый поиск и WMS proxy. Массовый GEO запускается
в фоне, отображает прогресс и пишет снимки в БД. Карточку объекта необходимо
проверять вручную перед инвестиционным или юридическим решением.

## Проверки

```powershell
python -m pytest -q tests/test_geo_cadastral.py tests/test_ai_geo_reliability.py tests/test_status_geo_pipeline.py
```

Сетевые acceptance-тесты зависят от текущей доступности НСПД/PKK и не заменяют
детерминированные unit tests с fixtures.

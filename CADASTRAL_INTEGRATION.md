# Интеграция кадастрового поиска

## Обзор

Система BankrotAI интегрирована с публичной кадастровой картой Росреестра (ПКК) для получения детальной информации об объектах недвижимости по кадастровым номерам.

## Архитектура

### 1. Модуль геокодирования (src/bankrotai/geo.py)

#### CadastralGeocoder
Класс для работы с API Росреестра:
- **Endpoint**: `https://pkk.rosreestr.ru/api/features/5`
- **Rate limiting**: 2 секунды между запросами
- **Timeout**: 10 секунд

**Метод `search(cadastral_number: str)`**:
Возвращает полную информацию об объекте:
- Координаты (centroid_lat, centroid_lon)
- Геометрия границ (geometry_json) в формате GeoJSON
- Тип объекта (object_type)
- Адрес (address)
- Назначение (purpose)
- Площадь (area_value, area_unit)
- Кадастровая стоимость (cad_cost)
- Этажность (floors)
- Год постройки (year_built)
- Год ввода в эксплуатацию (year_commissioning)
- Статус ОКН (cultural_heritage)
- Кадастровый квартал (cadastral_quarter)
- Даты создания и оценки (date_create, date_cost)

### 2. Хранение данных (src/bankrotai/db.py)

#### LotGeoSnapshot
Таблица для хранения геоданных лотов:
- `geometry_json` (JSON) - границы объекта в формате GeoJSON
- `metadata_json` (JSON) - полная информация из кадастра (17+ полей)
- `geo_source` - источник данных (cadastral/osm)
- `geo_method` - метод получения (cadastral/address)
- `geo_confidence` - уровень уверенности (high/medium/low)

### 3. Извлечение данных (src/bankrotai/extractors.py)

Новые функции для парсинга описаний лотов:
- `extract_year_built()` - год постройки (1800-2030)
- `extract_commissioning_year()` - год ввода в эксплуатацию
- `extract_cultural_heritage()` - определение объектов культурного наследия

### 4. GUI интерфейс (src/bankrotai/gui.py)

#### Вкладка "Карта и Кадастр"
**Левая панель - Карта**:
- Leaflet + OpenStreetMap базовая карта
- WMS слой Росреестра (кадастровые границы)
- Кластеризация маркеров лотов
- Кнопка "Обновить метки"
- Чекбокс "Кадастровый слой"

**Правая панель - Поиск**:
- Поле ввода кадастрового номера
- Кнопка "Найти объект"
- Область результатов с детальной информацией

#### JavaScript API
```javascript
window.setCadLayerVisible(visible)  // Включение/выключение кадастрового слоя
window.showCadastreObject(data)     // Отображение объекта на карте
```

## Использование

### Поиск объекта по кадастровому номеру

1. Откройте вкладку "🗺️ Карта и Кадастр"
2. Введите кадастровый номер в формате `XX:XX:XXXXXX:XXXX`
   Пример: `76:23:010101:15008`
3. Нажмите "🔎 Найти объект"
4. Результаты отобразятся в правой панели
5. Объект автоматически отобразится на карте

### Включение кадастрового слоя

Установите флажок "Кадастровый слой" для отображения границ всех кадастровых участков на карте.

### Автоматическое обогащение лотов

При импорте лотов система автоматически:
1. Извлекает кадастровые номера из описания
2. Запрашивает данные из ПКК Росреестра
3. Сохраняет координаты и метаданные в БД
4. Использует данные для оценки и анализа

## Приоритет источников геоданных

1. **Кадастровый номер** (если есть) - самый точный источник
2. **Адрес через Nominatim** (если кадастра нет) - fallback

## Формат кадастрового номера

Стандартный формат: `XX:XX:XXXXXX:XXXX`
- XX - код региона (2 цифры)
- XX - код района (2 цифры)
- XXXXXX - номер квартала (6-7 цифр)
- XXXX - номер участка (1-10 цифр)

Примеры:
- `76:23:010101:15008` - Ярославская область
- `77:01:0001075:1234` - Москва
- `50:20:0000000:123` - Московская область

## Ограничения

- **Rate limiting**: 2 секунды между запросами к ПКК
- **Timeout**: 10 секунд на запрос
- **Доступность**: Зависит от работы серверов Росреестра
- **Формат**: Только российские кадастровые номера

## Обработка ошибок

Система корректно обрабатывает:
- Неверный формат номера
- Отсутствие объекта в ЕГРН
- Таймауты и сетевые ошибки
- Отсутствие координат или границ

## Интеграция с оценкой

Кадастровые данные используются в scoring:
- Год постройки влияет на оценку состояния
- ОКН снижает ликвидность (-20 баллов)
- Кадастровая стоимость сравнивается с ценой лота
- Площадь валидируется с данными из описания

## Примеры использования API

### Python
```python
from bankrotai.geo import CADASTRAL_GEOCODER

result = CADASTRAL_GEOCODER.search('76:23:010101:15008')
if result:
    print(f"Адрес: {result['address']}")
    print(f"Площадь: {result['area_value']} {result['area_unit']}")
    print(f"Координаты: {result['centroid_lat']}, {result['centroid_lon']}")
```

### Обогащение лота
```python
from bankrotai.geo import enrich_lot_geo
from bankrotai.db import session_scope, ProcessedLot

with session_scope() as session:
    lot = session.get(ProcessedLot, lot_id)
    if enrich_lot_geo(session, lot):
        print("Геоданные добавлены")
```

## Техническая информация

### WMS слой Росреестра
```
URL: https://pkk.rosreestr.ru/arcgis/services/Cadastre/Cadastre/MapServer/WmsServer
Layers: 1-24 (все кадастровые слои)
Format: image/png
Transparency: 70%
```

### Структура geometry_json
```json
{
  "type": "Polygon",
  "coordinates": [
    [[lon1, lat1], [lon2, lat2], ...]
  ]
```

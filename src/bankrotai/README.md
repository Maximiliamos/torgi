# BankrotAI Pro

Актуальное описание проекта, результаты аудита, запуск, проверки и замечания находятся в корневом файле:

```text
../../README.md
```

Этот файл оставлен только как указатель, чтобы внутри пакета не лежала устаревающая копия документации.

Desktop launcher: `start_bankrotai.bat`. Он вычисляет корень проекта относительно
своего расположения, выбирает самую новую EXE-сборку и использует source fallback
только если EXE отсутствует. Проверка без запуска: `start_bankrotai.bat --check`.

# BankrotAI Pro

Актуальное описание проекта, результаты аудита, запуск, проверки и замечания находятся в корневом файле:

```text
../../README.md
```

Этот файл оставлен только как указатель, чтобы внутри пакета не лежала устаревающая копия документации.

Desktop launcher: `START_TORGI.bat` в корне проекта. Он запускает единственную
актуальную сборку `app\BankrotAI.exe` и использует source fallback через Python
только если EXE отсутствует. Проверка без запуска: `START_TORGI.bat --check`.

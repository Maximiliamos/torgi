BANKROTAI — АКТУАЛЬНАЯ СВОДКА (2026-07-31)

Основной запуск Windows:
  start_bankrotai.bat

Проверка launcher без запуска:
  start_bankrotai.bat --check

Основная сборка:
  dist_operating_model\BankrotAI.exe

Ключевые возможности:
  - ГИС «Торги», TBankrot, РАД / ЛОТ-ОНЛАЙН, HTML/Excel импорт и connector SDK;
  - официальный ЕФРСБ Publications API connector (нужны credentials оператора);
  - CanonicalLot и SourceLot для нескольких площадок;
  - параметры процедуры, задатки, сроки и участие;
  - версии документов по SHA-256;
  - GEO/кадастр с обязательной TLS-проверкой;
  - предварительный AI-анализ с provenance и human review;
  - калькулятор максимальной ставки без автоматической подстановки AI-цены;
  - SQLite desktop и PostgreSQL/Redis/Celery web production-контур.

# Исправления по результату полного обхода 20 ноября

Обход 09:00 МСК включил все 19 источников, но завершился по общему четырёхчасовому лимиту. Семь из 13 дополнительных ЭТП завершились; шесть потребовали исправлений.

| Случай | Причина и изменение |
|---|---|
| АРБбитЛот | Официальный классификатор «Здания (помещения) жилые, не входящие в жилищный фонд» содержит 53 символа. PostgreSQL отвергал `property_type VARCHAR(50)`. Колонка расширена до TEXT с миграцией, без обрезания факта источника. Обратная миграция отказывает при потере данных |
| Аукцион-центр | У собственного лота `103469774:4` слово «транспортное» описывает назначение сооружения. Оно больше не распознаётся как транспортное средство. Настоящий автомобиль в смешанном лоте сохраняет отрицательную проверку |
| Вердиктъ | У `102286319:19` номер дома 3 склеивался с отдельной ценой 45 900 рублей и превращал её в 345 900. Заголовок и цена теперь извлекаются из отдельных DOM-элементов. Номер дома сохраняется; строгое сравнение цены с собственной карточкой сохраняется |
| Уральская / Объединённая площадки | Реальные каталоги продолжаются после 500 страниц. Для больших ASP.NET-каталогов установлен ограниченный бюджет 6000 страниц; достижение фактического конца остаётся обязательным. АРБбитЛот использует тот же запас для полного выбранного каталога |
| RUSSIA OnLine | Общий таймер отсчитывался от старта всех источников; собственный обход был прерван через примерно 55 минут. Бюджет задачи расширен до 8 часов с аварийным потолком 9 часов, внутри 12-часового интервала расписания |

Если обязательная карточка дополнительной ЭТП не прошла проверку, её сведения из каталога не создают новый лот и не перезаписывают проверенные факты существующего. Диагностика сохраняется в неуспешном SourceRun; такая ошибка не превращается в успешный полный обход. Прежняя отдельная политика отказов НИСТП сохраняется. Проверены оба пути записи и сохранность ручной оценки.

Исправлено сопоставление имён этапов NSPD/IK12 с фактическими поставщиками при восстановлении GEO-повторов. Снимается ожидание только после более свежего положительного результата именно этого поставщика; неизвестные этапы остаются заблокированы.

Локально прошли 71 проверка карточек/классификации/миграции, 80 проверок сохранения данных, 72 проверки расписания/восстановления, Ruff и mypy 208 модулей. Есть отдельная PostgreSQL-регрессия на официальный классификатор длиной более 50 символов. Граница каждого полного каталога дополнительно измеряется без записей в production.

Полный CI текущего SHA, развёртывание миграции и повторные завершённые обходы шести источников обязательны. Наличие исправления в коде ещё не является доказательством успешной полной загрузки. Отсутствующие лоты не архивируются; новые удаления записей, оценок и истории этим изменением не выполняются.

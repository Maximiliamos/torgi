# P1: источники торгов и исключённые координаты — read-only проверка

Этот отчёт НЕ исправляет данные, НЕ обращается к первоисточникам и НЕ меняет карту.

В окружении проекта с доступной БД выполнить:

```powershell
python scripts/audit_p1_source_geo_evidence.py --output p1-evidence.json --max-samples 2000
```

Результат:
- свежесть и полнота последних подтверждённых обходов по каждому источнику;
- контроль проблем статусов, цен, дат и дублей в локальной БД;
- список объектов с координатами вне региона (идентификатор, кадастр, регион, причина);
- состояние согласования локальной БД и опубликованной карты.

**Важно:** наличие `status=success` у источника не доказывает реальную полноту внешнего реестра. Для приёмки требуется сравнить случайную и заведомо сложную выборку идентификаторов с официальным источником. Статусы `expired`, `archived` и `active` нельзя менять массово по результатам одного отчёта.

`p1-evidence.json` может содержать кадастровые номера и идентификаторы объектов — хранить локально, не отправлять в публичные артефакты GitHub Actions.

Данные из текущего запуска 28.10.2026: публикация новой карты прошла, но сборщик исключил 1 125 объектов с несовпадением региона и 57 объектов с неподдерживаемым кодом региона. Их нужно проверять адресно; причиной может быть неверная привязка региона, а не сама координата.

После подтверждения причины для каждого лота:
1. исправить только исходную проблемную связку (регион, кадастр, GEO evidence);
2. выполнить тесты геосанитарии/дедупликации;
3. только после этого перестроить карту и сравнить DB → dataset → REG.RU.

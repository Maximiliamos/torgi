# «Торги России»: доступность для persistent ingestion

Проверено 22 августа 2026 года для публичного каталога `https://торги-россии.рф`.

- Каталог недвижимости публично виден в интерактивном браузере.
- Карточки имеют стабильный URL вида `/lot/{numeric_id}`.
- Пагинация публичного каталога использует `/search?categorie_childs[]=7&history_only=0&page=N` (для жилой недвижимости было опубликовано 200 страниц).
- Карточка каталога содержит регион, ссылку на ЭТП и описание объекта.
- Неаутентифицированный программный HTTP GET к тому же `/search` получает `403`, поэтому существующий `requests`-клиент не может безопасно перечислить страницы.

Проект не обходит CAPTCHA, anti-bot protection или access controls. До появления документированного API либо разрешённого server-to-server доступа «Торги России» остаётся недоступным для полного автоматического сканирования. Три доступных источника (`torgi.gov.ru`, `tbankrot.ru`, `lot-online.ru`) продолжают обновляться независимо; данные недоступного источника нельзя архивировать из-за неуспешного запуска.

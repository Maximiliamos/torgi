# Запуск ЭТП и GEO без VPN

Сценарий предназначен для Home production-хоста, когда VPN нужен для Codex,
но мешает доступу Docker-воркеров к российским ЭТП, НСПД и другим GEO-сервисам.

## Запуск оператором

1. Дождаться, пока изменения этого сценария окажутся в `main` и Home deploy
   завершится успешно.
2. Открыть обычный PowerShell в корне репозитория.
3. Отключить VPN.
4. Выполнить:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run-etp-off-vpn-map-campaign.ps1
   ```

Сценарий можно безопасно запустить повторно после устранения сетевой ошибки.
Он сначала проверяет exact SHA production-контейнеров, затем запускает
изолированный QA-прогон всех 21 профилей ЭТП без записи в БД. После этого он
запускает обязательный exact-SHA P1, повторяет P11 до пяти раз, ожидая
восстановления фоновых source/GEO probes, и ждёт штатную цепочку S5 и
`ETP verified canary GEO and public map`.

Во время работы сценарий печатает общий процент от 0 до 100, название текущего
этапа, активный шаг GitHub Actions и прошедшее время. Heartbeat появляется не
реже одного раза в 30 секунд, даже если процент не изменился из-за ожидания
ответа ЭТП/GEO. В журнале первого workflow дополнительно видны
`completed_sources`, `total_sources` и точный процент обхода 21 ЭТП.

Полный локальный transcript каждого запуска сохраняется в
`D:\BankrotAI\etp-operator-logs\etp-off-vpn-map-YYYYMMDD-HHMMSS.log`. Путь
печатается в начале, при успешном завершении и при любой ошибке. В журнал входят
SHA production-образа, проценты, активные шаги, время, ссылки на все запуски и
текст причины остановки. GitHub Actions независимо хранит QA report/progress,
P11 evidence и S5 readiness artifact, поэтому диагностика остаётся доступной,
даже если локальное окно PowerShell было закрыто.

Запись остаётся ограниченной существующим production workflow: не более двух
подтверждённых лотов на источник `m-ets.ru`/`cdtrf.ru`, только после свежего
restore-verified backup, повторной проверки конфликтов и exact-SHA acceptance.
При отсутствии подтверждённых координат публикация завершается ошибкой, а не
создаёт приблизительную метку.

Успешное завершение печатает ссылку на карту и два публичных source-фильтра.
При ошибке нужно открыть последнюю напечатанную ссылку GitHub Actions; обходить
проверки или запускать импортирующий Python-модуль вручную не следует.

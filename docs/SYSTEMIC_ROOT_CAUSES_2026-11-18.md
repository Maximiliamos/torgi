# Причины ошибок и границы подтверждения

Дата среза: 18 ноября 2026. Основание — исходные 44 обращения по 41 лоту,
полный внутренний аудит 239676 ProcessedLot и проверки первичных площадок.
Кандидат детектора не считается ошибкой до проверки источника.

## Доказательства и ограничения

- Приватные артефакты: `.artifacts/finish/systemic-database-baseline.json`,
  `systemic-database-after-1181-repairs.json`, `reports-resolution-audit.json`,
  `tbankrot-safe-*-result.json`, `gov-safe-20261118a-*-result.json`,
  `gov-entire-verified/manifest.json`, `geo-p0-current-20261118.json`.
- Для всех 44 исходных обращений есть индивидуальный outcome; 38 уникальных
  лотов удалены по прямому указанию пользователя, 3 исправлены. Это история
  обработки обращений, а не доказательство устранения всех классов дефектов.
- TBankrot остановлен после HTTP 429. У сохранённых карточек нет достаточных
  procedure/lot ссылок для точного массового соединения с первичными ETP.
  Один совпавший кадастр не разрешает перенос цены, дат и статуса.
- Собранные GIS доказательства покрывают доступные поля точных карточек.
  Пустые поля, фотографии вне XLSX и последующие изменения источника остаются
  отдельными ограничениями. Сбор не равен применению и проверке результата.
- Все новые исправления сохраняют оценки/заметки; проверки digest входят
  в ограниченные транзакции. Новых массовых удалений по кандидатам нет.
- Технический P1/P11 success подтверждает проверенные инварианты конкретного
  deployed SHA и карты, а не абсолютную достоверность всех внешних фактов.

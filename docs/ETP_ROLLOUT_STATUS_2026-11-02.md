## Измеримый прогресс ETP-трека

Единого процента «готовности всех ЭТП» нет: регистрация профиля, чтение первой
страницы, полный проход, качество полей и production-карта — разные критерии.
Текущий прогресс выражается следующими знаменателями.

| Критерий | Результат | Интерпретация |
|---|---:|---|
| Профили в read-only inventory | 22/22 (100%) | Все зарегистрированные профили проверяются без записи |
| Новые профили с runnable production campaign | 16/21 (76%) | 5 профилей остаются заблокированными доказательствами/доступом |
| Источники с production-записями среди 16 runnable | 3/16 (19%) | CDTRF, МЭТС, Sistematorg |
| Источники с успешным полным source-run последней общей кампании | 2/16 (13%) | МЭТС и Sistematorg; это не означает полную source acceptance |
| Источники с опубликованными точками на карте | 3/16 (19%) | Координаты есть не у всех импортированных записей |
| Единый контракт нормализации всех источников | 0/1 | GitHub #1021 открыт; работа начинается после завершения CDTRF |

Read-only inventory [run 41366336457](https://github.com/Maximiliamos/torgi/actions/runs/41366336457)
успешно проверил 22 профиля без DB writes. Его результат — диагностика
доступности, а не разрешение production ingestion: 14 источников дали
`blocked_or_parser_error`, 5 требуют доказать публичный каталог/пагинацию,
1 вернул изменившийся HTML/нет совпадений и 2 используют существующие
коннекторы.

**Этап R7-CDTRF: production completion and acceptance.** Реализация уже не
`implementation_in_review`, но ещё не `production_accepted`.

Критерий выхода из этапа:

1. успешный полный проход всех объявленных страниц на текущем exact SHA;

3. количество каталога объяснимо относительно официальных четырёх статусов и

5. ручная проверка минимум 30 карточек, включая квартиры, землю, коммерческую
   недвижимость, доли/права и карточки без кадастра;
6. exact-SHA P11 success и сохранённый операторский лог.

### P2 — вводить оставшиеся ЭТП по одной

→ GEO/map → ручная проверка владельцем. Не повторять массовый write-run всех
источников, пока первый источник с ошибкой не разобран и не принят.

# P1: внешний контур и независимость от зарубежных сервисов — 28.10.2026

Статический срез по исходным файлам `main`, НЕ захват фактического DNS или трафика.

| Компонент | Строки, найденные в коде | Статус |
|---|---|---|
| Аукционы | `torgi.gov.ru`, `tbankrot.ru` | Российские источники |
| Геокодирование | `nspd.gov.ru`, `pkk.rosreestr.ru` | Российские публичные источники |
| Карта/S3 | `s3.regru.cloud` | Российское объектное хранилище |
| Геокодирование | `nominatim.openstreetmap.org` | Зарубежный инфраструктурный fallback; наличие в коде НЕ доказывает активные запросы |
| Геокодирование | `api.roscadastres.com` | Домен требует проверки реального оператора и DNS; нельзя классифицировать только по TLD |
| AI-провайдеры | `api.deepseek.com`, `api.x.ai`, `api.groq.com`, `models.github.ai`, `integrate.api.nvidia.com`, `generativelanguage.googleapis.com`, `api.kiro.ai` | Опциональные интеграции: проверить фактический `AI_PROVIDER` без разглашения секретов |
| WEB edge | Cloudflare / `wrangler` deployment | Зарубежная инфраструктура может быть критической частью пользовательского пути; требуется live DNS/CNAME и проверка отключения |
| Сборка/исходники | `raw.githubusercontent.com`, GitHub, npm, PyPI | Иностранные сервисы для развёртывания/зависимостей, не обязательно runtime-зависимости |

В проекте в `core.py` есть local OmniRoute proxy (localhost); присутствие иностранных AI API в `ai.py` не означает, что они включены. Для аудита без VPN необходимо отдельно измерить реальные outbound запросы процессов на Home, DNS трассировку `sterdez.online`, загрузку Yandex Maps, внешние JS и поведение при отказе каждого сервиса.

**Нельзя** массово удалять библиотеки, DNS-конфигурацию или foreign API-провайдеров до подтверждения их использования. Минимальный приёмочный тест: рабочие поиск, карточка, геокодирование и карта без VPN при ограничении доступа к иностранным API; состояние деградировавшего функционала явно отражено в интерфейсе.

Проверка по локальным исходникам: `python scripts/audit_external_dependencies.py --output external-domains.json`. Статический отчёт не подтверждает расположение серверов, CNAME, скрытые динамические вызовы и доступность с домашнего провайдера.

# РАД / ЛОТ-ОНЛАЙН

BankrotAI выполняет поиск по публичному каталогу
`https://catalog.lot-online.ru/` без авторизации. В desktop-приложении для этого
есть отдельная вкладка «Поиск РАД / ЛОТ-ОНЛАЙН».

Поддерживаемые параметры:

- каталог недвижимости или все категории;
- Ярославская область либо все регионы;
- активные, архивные или все лоты;
- текстовый запрос;
- одна страница или автоматическая загрузка всех страниц с лимитом.

Каждая карточка получает стабильный внешний ID `lot-online:<product_id>`,
источник `lot-online.ru`, номер процедуры РАД, стартовую цену, ссылку, регион и
признак активности. При импорте данные проходят общий `persist_lot`, поэтому
создаются или обновляются `ProcessedLot`, `SourceLot` и `CanonicalLot`.

## Использование

1. Откройте вкладку «Поиск РАД / ЛОТ-ОНЛАЙН».
2. Выберите каталог, регион и состояние лотов.
3. Нажмите «Найти на ЛОТ-ОНЛАЙН».
4. Откройте карточку двойным щелчком или импортируйте выбранные/все результаты.

В режиме «Загрузить все страницы» результаты сохраняются порциями после каждой
страницы. Кнопка «Остановить» завершает поиск после текущего HTTP-запроса.

Источник является внешним HTML-каталогом. Если его разметка или feature-коды
фильтров изменятся, BankrotAI покажет ошибку или пустой результат; приложение не
создаёт вымышленные карточки и сохраняет URL фактического запроса в диагностике.

# Проверенные входы источников и варианты идентификаторов

Полный пакет четырёх площадок остановился после 9,100 применённых записей на
NUL в описании Рус-Онлайн. Последняя транзакция откатилась. Полный read-only
просмотр 18,810 подготовленных записей нашёл ровно два таких описания:
`rus-on.ru:14483` и `rus-on.ru:14125`. Остальные поля этих карточек не объявлены
ошибочными. Исходные captures и их SHA остаются неизменными.

Нормализация текстов Рус-Онлайн теперь заменяет NUL пробелом. Verified source
repair дополнительно отвергает ненормализованный NUL до записи любых полей.
Повторная подготовка двух карточек должна использовать исходные captures и
время наблюдения, новый parser и отдельные immutable evidence files.

Отдельно обнаружены два исторических написания точного M-ETS trade/lot ID:
`m-ets.ru:241542-1` и `241542-1`. Durable exclusion теперь проверяет оба варианта
только для точного числового идентификатора M-ETS. Другой номер лота, источник,
кадастр или bare procedure ID не считаются алиасом. Удалённая по решению
пользователя карточка не должна возвращаться из-за изменения формата ID.

Read-only census выявил 1,846 пар существующих M-ETS записей с такими
написаниями; у них нет пользовательских оценок. Этот патч их не удаляет и не
переносит оценки. Сверка первичных карточек и bounded identity repair остаются
отдельной частью общего плана. Наличие алиаса не доказывает текущую цену,
статус, даты или полную идентичность bare procedure записи другой площадки.

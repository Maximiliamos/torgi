# Подтверждение контракта ГИС Торги, 2026-11-18

Первичная публичная карточка проверена через официальный API с точным
совпадением `id`, без поиска по кадастру. Полные JSON-снимки и SHA сохранены
в приватных артефактах; отсутствие поля не является основанием очистить БД.

Официальный frontend:
https://torgi.gov.ru/new/3748.e97e0591536614b3.js

SHA256: `d753080152d011b0a7f9a71ef3c8f2268dbdc70562eb64fabfaaa63f558553d5`.
В словаре LotStatus `SUCCEED` подписан «Состоялся», `FAILED` — «Не состоялся»,
`APPLICATIONS_SUBMISSION_SUSPENDED` — «Прием заявок приостановлен».
Прежний parser не распознавал SUCCEED, а проверка подстроки SUBMISSION
ошибочно принимала приостановленный приём за active. Исправлено точное
сопоставление кодов до эвристических fallback; неизвестные коды остаются unknown.

В полученных официальных JSON присутствуют `biddStartTime`,
`noticeFirstVersionPublicationDate`, `deposit`, `priceStep`, `noticeNumber`.
Они проецируются отдельно от окончания приёма и даты начала аукциона;
UTC timestamps нормализуются в принятую в приложении Europe/Moscow.
`current_price`, полученная fallback из начальной цены, не считается
независимо подтверждённой текущей ценой при операторском ремонте.

Проверка охватывает все 61 872 сохранённых GIS ID, включая архив;
фактически проверенный счётчик и ошибки записываются в журнал. Запуск
не означает завершение всей сверки. У 230 из первых 284 успешно проверенных
карточек был SUCCEED, ранее нормализовавшийся в unknown. Это наблюдение
по началу прохода, не оценка распространённости по всей базе.
